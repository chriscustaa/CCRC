# Why this replay is still decision-relevant

The strongest current finding is not that “V2 is better than V1.” That identity contrast failed to replicate. The stronger and repeatedly supported finding is that verifier judgments are sensitive to answer representation and display position.

The evidence now points in four directions:

1. **Slot/representation sensitivity is the dominant live mechanism.** consensus600 over-selected display C and performed worst when truth appeared in D. In I5-1000, correct-slot assignment was nearly balanced yet accuracy still ranged from 32.4% in B to 72.2% in C, while display C was again over-selected. Within-item changes in answer under different permutations make pure item-difficulty explanations implausible.
2. **Verifier efficacy remains unresolved.** Like-for-like pooled controller outcomes are 12 repairs and 4 harms, but they are post hoc and contaminated by the verifier permutations. This is promising enough to test and not clean enough to trust.
3. **The θ=.20 gate is useful but no longer the main uncertainty.** Across the two audited cohorts it captured 45 baseline errors among 62 routed items. The remaining question is what corrective action, if any, should follow routing.
4. **I5 is not a viable branch.** It did not improve absolute B or D performance and did not improve the θ=.20 controller. Future architecture should remain no-I5.

The 568-cell replay is therefore a high-value stop/go test. It directly targets the variable most capable of invalidating the controller result and reuses already exposed items rather than spending a fresh confirmatory sample prematurely.

The most likely qualitative result is that slot sensitivity persists and some of the apparent verifier benefit attenuates. The important unknown is whether the controller's net sign remains stably positive after balancing. If it does, stop exploring and run one fresh powered confirmation. If it does not, kill this verifier actuator and stop spending calls on it. No additional speculative branch is warranted before this result.
