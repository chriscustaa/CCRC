# License notes

The harness code is experiment scaffolding. The bundled replay questions derive from the `cais/mmlu` dataset mirror; its dataset page identifies the MMLU license as MIT. The original benchmark is associated with Dan Hendrycks, Collin Burns, Steven Basart, Andy Zou, Mantas Mazeika, Dawn Song, and Jacob Steinhardt, “Measuring Massive Multitask Language Understanding,” ICLR 2021.

This package also contains hashes and derived outcome metadata from user-supplied experiment bundles. Those provenance artifacts are included for research reproducibility and do not change the upstream dataset terms.
