# Why this branch has value

The completed program established two facts that now have to be reconciled:

1. A low first-token logprob gap strongly enriches for baseline error.
2. Acting on that uncertainty with the verifier controller did not produce reliable net benefit in the fresh 7,818-item confirmation because harms rose to nearly match repairs.

The missing distinction is **recoverability**. Some low-gap answers are wrong and can be corrected; others are correct but fragile and can be damaged by intervention. A single confidence value describes state, not response direction.

This pilot asks whether standardized depth interventions expose a usable response pattern: stable late correction with rising, control-centered confidence. It is deliberately cheap and falsifiable. If the frozen truth-blind rule is nonpositive, the branch stops. If it clears a demanding engineering screen, it earns a fresh 300-item development test before any new large confirmation is considered.
