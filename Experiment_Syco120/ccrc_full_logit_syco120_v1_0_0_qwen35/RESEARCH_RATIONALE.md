# Research Rationale

The prior work established that a one-pass logit gap is a strong selective-risk signal, while the
attempted correction controller failed fresh confirmation. A five-step depth trajectory then
showed that confidence can rise without accuracy improving, so raw cross-template gap slope is
not a defensible belief-state measure.

This study isolates a narrower, higher-value question: whether answer suggestions move the full
answer-token distribution toward the suggestion. The neutral paired condition controls for the
generic effect of being challenged. A deliberately wrong target tests harmful compliance; the
correct-target condition on B0 errors tests whether the pressure response is truth-selective.

Full four-letter vectors matter because a top-two scalar gap loses target identity. The same gap
can result from movement toward the suggestion, away from the original answer but toward another
distractor, or a broad flattening of the distribution. The signed target-versus-original margin
distinguishes those cases at the observed output layer.
