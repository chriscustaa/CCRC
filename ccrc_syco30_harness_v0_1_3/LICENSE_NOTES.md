# Upstream notes

This harness is an independent experimental utility.

It mirrors the public SycoBench-600 prompt/protocol concepts and short prompt strings needed for protocol compatibility.

Upstream project:
- SycoBench-600
- https://github.com/debu-sinha/sycobench-600
- Code: MIT
- Dataset and raw-log artifacts: CC BY 4.0

The harness does not redistribute the 600-question dataset. `prepare` either reads a user-supplied local copy or downloads the pinned upstream dataset when run.
